PDF Fiel

Direção visual A mantém as decisões das imagens do PDF: desktop fixo, fundo branco, linhas finas, cinza claro para seleção, avatares circulares com iniciais, bolhas enviadas pretas e modais brancos sobre scrim cinza.

Conceito

Aplicativo de mensagens objetivo, neutro e de baixa ornamentação.

Personalidade

Pragmática, limpa, silenciosa, confiável.

Densidade

Média-alta. Prioriza histórico e lista lateral, sem visual de dashboard.

Vantagens

Menor risco de divergência com o enunciado; implementação simples; estados muito claros.

Desvantagens

Marca pouco expressiva; depende de precisão de espaçamento para não parecer genérica.
